# Project Phoenix

A game jam project exploring a galaxy of piloted combat robots, mysterious artifacts, and the people who bring them to life. Our visual direction blends drawn 2D characters with stylized 3D and soft cel shading.

Project Phoenix is our working title. The game is currently in brainstorming and early prototype preparation.

## Project folders

| Folder | Purpose |
| --- | --- |
| [`prototype/`](prototype/) | Playable prototype, game code, and game assets. |
| [`web/`](web/) | Project website and its assets. |
| [`marketing/`](marketing/) | Promotional images, copy, trailers, and other marketing materials. |
| [`ThePixelPool/`](ThePixelPool/) | Editable production source files before export and deployment. |

## Production source assets

**ThePixelPool** holds the original editable assets:

- [`3D/`](ThePixelPool/3D/): models, scenes, rigs, and animations.
- [`textures/`](ThePixelPool/textures/): texture and material source files.
- [`illustrations/`](ThePixelPool/illustrations/): layered drawings, concept art, and character artwork.
- [`logos/`](ThePixelPool/logos/): editable logo designs.
- [`icons/`](ThePixelPool/icons/): editable icons and UI artwork.

Keep source files in ThePixelPool, then place exported assets in the relevant `prototype/`, `web/assets/`, or `marketing/` folder. Production notes and documentation remain on Miro.
